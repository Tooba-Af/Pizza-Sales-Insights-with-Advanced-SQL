📊 Sales Performance Dashboard – Elevvo Internship
📌 Overview

This project is part of my Elevvo Internship (Data Analytics Track).
I built a Sales Performance Dashboard in Excel using the Superstore Dataset, focusing on data cleaning, analysis, and visualization to extract actionable business insights.

📂 Dataset

Source: Superstore Sales Dataset (Kaggle)

Contains sales records with details such as:

Order Date, Ship Date

Customer & Region Information

Product Category & Sub-Category

Sales, Profit, and Quantity

⚙️ Steps Performed

Imported dataset into Excel.

Cleaned & formatted raw data.

Built Pivot Tables for:

Total Sales

Total Profit

Units Sold

Average Order Value (AOV)

Created visualizations:

Monthly Sales Trend

Profit by Category & Region

YoY & MoM growth

Added Slicers for Region & Category filtering.

📊 Results / Insights

Identified high-performing months for sales.

Analyzed YoY growth trends.

Highlighted top-performing categories & regions.

Delivered a dynamic dashboard for quick decision-making.
